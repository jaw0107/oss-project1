# Vertical Shooter (S/W engineering proj 1)

화면 아래쪽 플레이어 비행기를 좌우로 움직이며 총알을 쏘아, 위에서 내려오는 적을 맞히는 종스크롤 슈팅 게임.

> 이 README 는 스타터에 들어 있던 것입니다. 제출 전에 아래 **[학생 작성]** 부분을 직접 채우세요.

## 실행 방법

- Python 3.10–3.13, pygame 2.x
  - Python 3.14 에서는 pygame 2.6.1 이 설치되지 않으니, 3.10–3.13 중 하나를 사용할 것.

```bash
pip install pygame
python main.py
```

## 조작

| 키 | 동작 |
|---|---|
| ← / → | 좌우 이동 |
| Space | 시작 화면에서 게임 시작 / 게임 중 총알 발사 |
| R | 게임 오버 후 다시 시작 |
| Esc | 종료 (시작 화면에서도) |

## 파일 구성

| 파일 | 내용 |
|---|---|
| `main.py` | 게임 루프 — 입력 처리, 갱신, 그리기, 점수·생명·게임 오버 |
| `entities.py` | 그림 불러오기(`load_frame`), 배경(`Background`), 스프라이트 클래스 — `Player`, `Bullet`, `Enemy` |
| `settings.py` | 화면 크기·속도·색 같은 상수 |
| `assets/` | 그림 — ansimuz CC0 픽셀 아트 (출처: `assets/CREDITS.md`) |
| `AI_USAGE.md` | 생성형 AI 사용 기록 |

## 구현한 기능 [학생 작성]

- [x] F1 플레이어 이동 - 좌우 방향키(`←`/`→`) 입력에 따른 이동 및 화면 좌우 경계(`0` ~ `WIDTH`) 이탈 방지
- [x] F2 총알 발사 - 플레이어 상단 중앙에서 총알 생성, 위로 이동 및 화면 상단 이탈 시 소멸, `Space` 키 발사 연결
- [x] F3 적 명중과 점수 - `groupcollide`를 이용한 총알-적 충돌 제거, 처치당 점수 가산 및 좌측 상단 `SCORE` 표시
- [x] F4 피격과 게임 오버 - 플레이어 피격(`spritecollide`) 및 적 하단 통과 시 생명 감소, 생명 0 이하 시 게임 오버 전환 및 중앙 `GAME OVER`·최종 점수 표시
- [x] F5 재시작과 최고 점수 - `highscore.txt`를 통한 최고 점수 읽기·쓰기 및 갱신, 게임 오버 화면 내 `HIGH SCORE`·재시작 안내 표시, `R` 키 입력 시 새 게임 시작
